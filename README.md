#  NLP Toxic Comment Classification

##  Project Overview

This project focuses on detecting toxic comments using Natural Language Processing (NLP) techniques. The model classifies text into toxic and non-toxic categories to help in content moderation systems.

---

##  Features

* Text preprocessing (cleaning, tokenization)
* Feature extraction using NLP techniques
* Machine Learning / Deep Learning model
* Toxic comment classification
* Performance evaluation

---

## 📊 Model Comparison

A comparative analysis of different machine learning models was performed using accuracy as the evaluation metric.

* KNN: 72.67%
* Decision Tree: 77.67%
* Bernoulli Naive Bayes: 88.67%
* Support Vector Classifier: 88.33%

The comparison clearly shows that **Bernoulli Naive Bayes outperformed other models**, making it the best choice for this problem.

---

##  Final Model

**Bernoulli Naive Bayes** was selected as the final model due to its superior performance and efficiency in handling text-based data.
